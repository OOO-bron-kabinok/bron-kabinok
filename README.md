# 🏫 Бронь Кабинки — IT.МОСКВА

Сервис для быстрого поиска свободных аудиторий и их бронирования в колледже **IT.МОСКВА**. Помогает студентам легко находить места для подготовки к занятиям, проведения встреч или собраний студенческих клубов.

*Учебный проект по учебной практике УП.12.*

---

## 🚀 Основной функционал

* **Визуальный мониторинг аудиторий:** Главный экран отображает список кабинетов или схематичный план этажа с понятной цветовой индикацией статуса:
  * 🟢 **Зеленый** — кабинет свободен прямо сейчас.
  * 🔴 **Красный** — кабинет занят (идет пара).
  * 🟡 **Желтый** — кабинет забронирован на будущее.
* **Детальное расписание:** При выборе любой аудитории открывается почасовой график ее занятости на нужную дату.
* **Умное бронирование:** Студент может выбрать свободное временное окно (например, с 16:00 до 18:00) и указать цель встречи (например, «подготовка к экзамену» или «собрание старост»). Система автоматически проверяет расписание на отсутствие накладок по времени.
* **Push-уведомления:** За 30 минут до начала забронированного времени приложение отправляет локальное напоминание.
* **Управление записями:** На отдельном экране «Мои брони» можно отслеживать все свои активные заявки и при необходимости отменять их в один клик.
* **Обратная связь** (если в кабинках грязно или что-то сломано).
* **Продление брони** После окончания основной брони можно её продлить.
